# Protect the Egg

A browser remake of an iPhone game from 2008. Tilt your phone to roll the egg, tap to fire lasers from its pointy end, and clear every ball before one cracks you.

- 5 lasers, one reloads every second
- Colored balls take more than one hit
- Screen edges wrap around, like Asteroids

**Play:** open `index.html` in a browser, or visit the GitHub Pages link. On a phone, allow motion access when asked, and use "Add to Home Screen" to launch it full-screen.

**Desktop controls:** WASD or arrow keys to move, mouse to aim, click or Space to fire, P to pause.
